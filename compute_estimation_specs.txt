StealthyIMU Model Replication: Compute & Estimation Specifications

======================================================================
1. DATASET CHARACTERISTICS
======================================================================
- Total Dataset Size: 30,693 samples
  * Training set: 24,554 samples
  * Validation set: 3,069 samples
  * Test set: 3,070 samples
- Average Sample Duration: ~4.06 seconds
- Input Modality: Smartphone motion sensor signals (Accelerometer & Gyroscope)
- Audio/Signal Sampling Rate: 500 Hz
- Feature Extraction: Spectrograms computed per coordinate axis
  * FFT size (n_fft): 80
  * Window length (n_win_length): 80
  * Hop length (n_hop_length): 20
  * Spectrogram features (n_feature): 31 channels per time step

======================================================================
2. MODEL ARCHITECTURES & MODEL SIZES
======================================================================
A. Teacher Model (Phase 1 - Paper Exact configuration)
- Model Size on Disk: ~36 MB
- Trainable Parameter Count: ~9.2 Million parameters
- Architecture details:
  * CNN: 1 2D-CNN block, output channels: (64, 128)
  * Time Pooling: Size 4 (reduces frame rate of features by 4x)
  * RNN: 4 layers of Bidirectional LSTM, hidden size: 256
  * Decoder: Attentional RNN Decoder (GRU-based), hidden size: 256, embedding size: 64
  * Target output units: 51 units (vocabulary size for semantic intents)

B. Student Model (Phase 2 - Knowledge Distillation)
- Model Size on Disk: ~2 MB
- Trainable Parameter Count: ~346,000 parameters
- Architecture details:
  * CNN: 1 2D-CNN block, output channels: (16, 32)
  * Time Pooling: Size 4
  * RNN: 2 layers of Bidirectional LSTM, hidden size: 64
  * Decoder: Attentional RNN Decoder (GRU-based), hidden size: 64, embedding size: 16
  * Target output units: 51 units

======================================================================
3. TRAINING SPECIFICATIONS
======================================================================
- Training Epochs: 30 epochs (original specs)
- Batch Size: 8 (from configuration)
- Loss functions:
  * Teacher: Sequence-to-sequence NLL loss
  * Student: Combined Loss (50% Seq2Seq NLL loss + 50% KL Divergence soft label loss)
- Optimizer: Adam, Learning Rate = 0.0003
- Compute Cost Benchmarks:
  * CPU Training Time (Estimated): ~90 hours
  * GPU Training Time (Estimated on NVIDIA T4/L40S): ~1.5 to 3 hours
